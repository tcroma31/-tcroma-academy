TCROMA ACADEMY - VERSION 1.1

NOUVEAUTÉS :
- Si fatigue >= 70, le joueur peut demander à ne pas être retenu
- Repos : -25 points de fatigue
- Le match est tout de même simulé
- Score du match affiché lorsque le joueur est absent
- Score affiché également en cas de blessure
- Classement mis à jour même sans le joueur
- Journal avec motif : repos, blessure ou suspension

PARCOURS :
- Retenu au Pôle Espoirs de Castelmaurou :
  * signature au pôle
  * sortie du championnat régional
  * championnat national jeunes
  * adversaires : réserves jeunes de clubs pros, INF Clairefontaine,
    Pôle Espoirs de Castelmaurou
- Non retenu :
  * poursuite en championnat régional
  * Tournoi des Violettes, Blanes et Cahors
- Détecté en tournoi :
  * centre de formation professionnel possible
  * niveau National/Ligue 3, Ligue 2 ou Ligue 1 selon réputation

INSTALLATION :
1. Extraire le ZIP
2. Ouvrir le dossier dans VS Code
3. Ouvrir index.html
4. Cliquer sur Go Live
5. Commencer une nouvelle carrière
